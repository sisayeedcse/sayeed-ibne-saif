# Sayeed Ibne Saif - Personal Portfolio

![Sayeed Ibne Saif - Portfolio](public/bg-hero-card.jpg)

A personal portfolio website built to showcase my projects, skills, education, and professional journey as a Computer Science & Engineering student aspiring towards Cloud & Infrastructure Engineering.

## 🚀 Tech Stack

This project is built using modern web technologies:

- **Framework:** [Next.js](https://nextjs.org/) (v16) with App Router
- **Library:** [React](https://react.dev/) (v19)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (v4)
- **Animations:** [Motion](https://motion.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## 📁 Project Structure

The project is structured with a modular architecture:

- `src/app/` - Next.js App Router layout and pages
- `src/components/` - Reusable UI components and sections
- `src/data/` - Static data files (profile, skills, projects, etc.) driving the content
- `src/lib/` - Utility functions
- `public/` - Static assets like images and documents
